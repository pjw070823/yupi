# 유피 Discord Bot

한국어 사용자를 위한 AI 대화 Discord 봇입니다. OpenRouter API를 통해 다양한 AI 모델을 활용하며, 대화 기록 저장 및 이미지 인식을 지원합니다.

## 기능

### 메시지 트리거

| 트리거 | 설명 | 모델 |
|--------|------|------|
| `유피야 [메시지]` | 대화 기록을 기억하는 메인 AI 대화. 이미지 첨부 가능 | DeepSeek V4 Flash |
| `멍청한 유피야 [메시지]` | 대화 기록 없는 가벼운 단발성 대화 | Gemma-2 9B |
| `매우 똑똑한 유피야 [메시지]` | 대화 기록 없는 고성능 AI 대화 | Gemini 2.5 Pro |
| `기출 [문항번호]` | 수능/모의고사 기출문제 이미지 직접 조회 | - |
| 정올 문제 링크 | 메시지가 `https://jungol.co.kr/problem/번호` 하나뿐이면 미리보기 이미지를 보내고 Discord 기본 임베드를 숨김 (봇에 메시지 관리 권한 필요) | - |
| 수식 입력 | 메시지가 수식으로만 이루어진 경우 자동 계산 | - |

> `유피야`에 이미지를 첨부하면 Vision 모델(Gemini 2.5 Flash-Lite)로 이미지를 분석합니다.

### 슬래시 커맨드

| 커맨드 | 설명 |
|--------|------|
| `/유피야 [내용]` | 대화 기록 기반 AI 대화 |
| `/chat [내용]` | 단발성 AI 대화 |
| `/calc [수식]` | 수식 계산기 |
| `/remind [시간] [메시지]` | 지정한 시간에 현재 채널에서 사용자를 핑하며 알림 |
| `/기출 [과목]` | 과목별 랜덤 기출문제 조회 (`수1` / `수2` / `미적`) |
| `/jungol register [정올id] [유저]` | 정올 계정(숫자 ID 또는 닉네임)을 서버의 정올 유저 목록에 등록 |
| `/jungol rank` | 서버에 등록된 유저의 AC 레이팅 순위표 (5분 캐시) |
| `/jungol profile [유저]` | 등록된 정올 프로필 조회 (기본은 본인) |
| `/jungol problem [번호]` | 정올 문제 정보와 미리보기 이미지 |
| `/리버스 스무고개` | 리버스 스무고개 게임 시작 (채널 단위) |
| `/리버스 포기` | 진행 중인 게임 종료 및 정답 공개 |

### 리마인드

슬래시 명령의 `시간` 칸을 입력합니다. `메시지` 칸은 선택 사항입니다.

- 시간 `+2d 1h 30m`, 메시지 `회의 준비` → 2일 1시간 30분 뒤 알림
- 시간 `261031 20:21`, 메시지 `회의 준비` → 2026년 10월 31일 20시 21분 알림
- `+`로 시작하는 시간은 `d`(일), `h`(시간), `m`(분), `s`(초)를 조합합니다. `+30s`, `+2m 30s`, `+2h30m10s`도 가능합니다. 각 단위는 한 번씩 사용합니다.
- 콜론 형식은 `+분:초` 또는 `+시:분:초`입니다. `+1:20`은 1분 20초, `+2:10:00`은 2시간 10분입니다. 첫 값은 자릿수 제한이 없으며, 콜론 뒤 각 값은 두 자리(00~59)로 입력합니다. 단위 문자와 콜론 형식은 섞지 않습니다.
- 절대 시각은 `YYMMDD HH:MM` 형식이며, 연도는 2000~2099년, 시간대는 한국 시간(KST)입니다.
- 미래 시각만 예약할 수 있으며, 메시지는 생략하거나 1900자 이하로 입력합니다. 알림은 `@사용자 [리마인드]` 다음 줄에 메시지를 굵게 표시합니다. 메시지를 생략하면 첫 줄만 보냅니다. 예약 확인은 본인에게만 보입니다.
- 알림은 입력한 채널에 보내며 신청자에게만 핑합니다. 메시지의 다른 사용자·역할·전체 멘션은 핑하지 않습니다.
- 예약은 `chattings.db`에 저장되어 재시작해도 유지됩니다. 봇이 꺼져 있는 동안 지난 예약은 다시 실행되면 발송합니다. 약 1초 간격으로 확인하며, 네트워크 상황에 따라 발송이 조금 늦을 수 있습니다.
- 일시적인 전송 오류는 1분 뒤 재시도합니다. 채널 삭제나 권한 부족으로 전송할 수 없는 예약은 실패로 기록합니다.
- 발송 직후 DB에 완료를 기록하기 전에 봇이 비정상 종료되면 같은 알림이 다시 발송될 수 있습니다.

리마인드 테스트: 의존성 설치 후 `python -m unittest discover -s tests -v` (Discord 접속 없이 실행).

### 리버스 스무고개

AI가 매 게임마다 무작위 주제를 받아 정답 단어를 창의적으로 정하고(최근 정답은 제외), 사용자가 `![제시어]`로 단어를 보내면 제시어와 정답 모두에 "네"라고 답할 수 있는 가장 구체적인 질문을 답장으로 보냅니다. (예: 정답 `햄버거`, 제시어 `!피자` → "패스트푸드인가요?")

- 게임은 채널 단위라서 채널의 누구나 제시어를 낼 수 있고, 가장 먼저 맞힌 사람이 이깁니다.
- 제시어가 정답과 사실상 같은 말(동의어, 줄임말, 외래어 표기, 띄어쓰기 차이 등)이면 정답으로 처리합니다.
- 의미 없는 문자열, 문장, 비속어 등은 "올바르지 않은 제시어입니다."로 답합니다.
- 글자 수·초성·받침 등 표기에 대한 질문과 정답 단어가 들어간 질문은 걸러내고 다시 생성합니다.
- 1시간 동안 입력이 없으면 게임이 자동 만료됩니다.
- 출제 주제, 프롬프트, 예비 정답 목록은 `reverse_twenty.py`에서 수정할 수 있습니다.

## 설치 및 실행

### 요구사항

```
discord.py
openai
python-dotenv
```

```bash
pip install discord.py openai python-dotenv
```

### 환경변수 설정

`.env` 파일을 생성하고 아래 값을 입력합니다.

```env
DISCORD_BOT_TOKEN=your_discord_bot_token
OPENROUTER_API_KEY=your_openrouter_api_key
```

### 실행

```bash
python bot.py
```

## 기술 스택

- **언어:** Python
- **Discord 라이브러리:** discord.py
- **AI API:** OpenRouter API
- **데이터베이스:** SQLite (`chattings.db`) — 사용자별 대화 기록 저장
